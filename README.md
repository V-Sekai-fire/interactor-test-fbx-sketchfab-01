# interactor-test-fbx-sketchfab-01

Third-party `.fbx` models, one directory per author, each with a JSON record of its author, source and licence, for testing scene importers.

## What it is for

A model sits beside a JSON file naming its author, source page and licence, so a test can attribute what it loads.

## Use

The models are data, so there is nothing to build.
